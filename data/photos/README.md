# Burger Photos

Drop restaurant-posted burger photos in this folder and reference them from `data/burgers.csv` or `data/photos.csv`.

Recommended naming:
- `restaurant-slug.jpg`
- `restaurant-slug.webp`
- `restaurant-slug.png`

The review cards default to each friend's uploaded burger photo. The image button on the top-right of a review card reveals the restaurant-posted photo listed here.
